## 基本メカニクス：シフトシステムの理解

本作は『8番出口』や『I'm on Observation Duty』といった名作異変探しゲームに着想を得た、心理的ループシステムを採用しています。プレイヤーはシフト1からスタートし、連続する校内セクターを前進しながらシフト8を目指します。

ゲームの黄金律はいたってシンプルです。**「周囲の環境を観察せよ」**。各セクターは、教室、寮の廊下、中庭、職員室といった見慣れた校内環境で構成されています。新しいフロアに入ったら、そのエリアが基準となる通常状態と完全に同じか、それとも呪いによる歪み（異変）が発生しているかを判断しなければなりません。

エリアが完全に正常であれば、そのまま出口の扉を通って次のシフトへと進みます。しかし、机の位置のズレ、あり得ない反射、不気味な怪異など、少しでも異変を見つけた場合は、直ちに引き返すか、指定された報告プロトコルに従う必要があります。判断を誤るとシフトカウンターがリセットされ、最初からやり直すことになります。

| シフト | 異変の発生頻度 | 脅威レベル | 主な目的 |
| :--- | :--- | :--- | :--- |
| **シフト 1 – 2** | 低（微細な異変が1つ発生する可能性あり） | 軽度 | 通常のフロア構造と環境音を記憶する。 |
| **シフト 3 – 4** | 中（視覚および聴覚の手がかり） | やや高 | 動く什器、消失したドア、音の歪みを発見する。 |
| **シフト 5 – 6** | 高（激しい環境変化） | 危険 | 高速で発生する幻覚やダミーの異変を識別する。 |
| **シフト 7** | 極めて高（怪異による追跡が発生） | 重大 | スタミナを管理しながら、複合して発生する異変の中を進む。 |
| **シフト 8** | 継続的（ボス戦突入） | 極限 | 儀式のシークエンスを解き、最後の呪いボスを撃破する。 |

上の進行表が示すように、難易度は劇的に上昇します。序盤のシフトを学習の機会として活用することで、後半のラウンドで見られる巧妙な変化を見抜くために必要な視覚的記憶を養うことができます。

## 異変の分類：視覚、聴覚、環境の脅威

生き残るためには、何を探すべきかを知っておく必要があります。学園内の異変は、一目でわかる怪物から、細部への注意力が試される極めて微小な変化まで多岐にわたります。コミュニティの報告によると、脅威は「物体の歪み」「構造の変化」「聴覚の異変」「直接的な呪いの具現化」の4つのカテゴリーに分類されます。

### 1. 物体の歪み
学校の一般的な備品に見られる微細な変化です。机が逆さまになっていたり、掲示板のポスターの顔写真が入れ替わっていたり、閉まっているはずのロッカーが開いていたりします。照明器具や掛け時計には特に注意してください。時計の針が逆回転しているのは典型的なサインです。

### 2. 構造および空間の変化
空間の異変は、校舎の構造そのものを歪めます。廊下が普段より明らかに長く見えたり、ドアの先が行き止まりのレンガ壁になっていたり、窓の外が中庭ではなく漆黒の虚無になっていたりします。以前は何もない壁だった場所に出入口が出現した場合は、直ちに引き返してください。

### 3. 聴覚および環境音の手がかり
音声をオフにしてプレイしてはいけません。シフトによっては、視覚的な手がかりが一切ない異変が発生することがあります。遠くで鳴る古い学校のチャイム、天井の上を歩き回る濡れた足音、誰もいないロッカーから漏れるかすかな囁き声などが聞こえることがあります。上級プレイヤーの間では、良質なヘッドフォンは必須装備とみなされています。

### 4. 敵対的な呪いの具現化
プレイヤーの進路に直接現れる活動的な怪異です。廊下の奥に佇む巨大な影、教室内を徘徊する歪んだマネキン、床板から伸びる無数の手など、活動中の怪異には迅速な対応が求められます。敵対的な異変には決して近づかないでください。その存在を確認したら、正しい境界線を通って直ちに退却しましょう。

| 異変カテゴリー | 主な具体例 | 発見難易度 | 推奨される対処法 |
| :--- | :--- | :--- | :--- |
| **物体の歪み** | 逆さまのポスター、配置の違う黒板、宙に浮く椅子 | 低〜中 | 入口のドアから引き返す。 |
| **構造の変化** | ループする廊下、消失した出口ドア、反転した天井 | 中 | 基準の構造を確認後、退却する。 |
| **聴覚の異変** | 逆再生されるチャイム、囁くような呪文、無人の部屋からの足音 | 高 | 立ち止まり、音の方向を聞き取ってから引き返す。 |
| **照明 / 影** | 点滅する蛍光灯、プレイヤーと一致しない不自然な影 | 中 | 影の角度を確認し、分離している場合は引き返す。 |
| **怪異との遭遇** | 徘徊する呪霊、廊下の亡霊、壁一面の目玉の群れ | 低（危険度：極大） | 直ちに視線を切り、即座に退却する。 |

これらのパターンを事前に把握しておくことで、パニックを論理的な問題解決へと変えることができます。ラウンドの合間にこの**呪術学校の異変 初心者ガイド**のチェックリストを確認すれば、精神的に大きなアドバンテージを得られます。

## 新入生のための必須サバイバル戦略

後半のシフトまで生き残るには、闇雲に突っ走るのではなく、計画的なアプローチが必要です。初心者の多くは廊下をダッシュで駆け抜け、怪異の敵視（アグロ）を買ったり微細なサインを見逃したりして失敗します。以下の基本テクニックを活用して生存率を高めましょう。

### 基準となる通常状態（ベースライン）を頭に叩き込む
シフト1を最初に歩く際は、急いではいけません。20〜30秒ほど時間をかけ、メインの廊下を左から右へと丁寧にスキャンしてください。ゴミ箱、消火器、掲示板、天井の照明パネルの位置を正確に記憶します。序盤のシフトは異変がないことが多いため、この最初の光景がマッチ全体の基準となる「記憶の写真」になります。

### セクター巡回ルート（スイープ）の徹底
セクターを探索する際は、一定の巡回ルートを守りましょう。決して当て所なく歩き回ってはいけません。熟練プレイヤーは、左側の壁を確認し、教室の窓を覗き、廊下の中央を調べ、右側の壁を確認してから出口の扉へ向かうというルートを推奨しています。

```
[入口] ---> 左側の壁（ポスター/ドア） ---> 廊下中央（床/天井）
               |                                  |
               v                                  v
[出口ゲート] <--- 右側の壁（ロッカー/窓） <--- 最奥部の確認
```

### スタミナとライトのバッテリー管理
懐中電灯は諸刃の剣です。隠された文字や影に潜む異変を照らし出してくれる一方で、点灯したままにしているとシフト6や7で徘徊する怪異を引き寄せてしまう可能性があります。暗い隅を調べる際や、不審な壁の質感を確かめる際だけ点灯するようにしましょう。ダッシュ用のスタミナは、怪異に追跡された際の緊急脱出用として温存してください。

| 巡回ステージ | 主な確認エリア | 避けるべき典型的なミス |
| :--- | :--- | :--- |
| **進入時** | 天井の照明・什器と最初のドア枠 | 上を見ずに前方へ駆け抜けてしまう |
| **廊下中間** | ロッカーの扉と掲示板 | ダッシュ中に微かな物音を聞き逃す |
| **教室の覗き込み** | 机の配置と窓ガラス | 退路を確保せずに教室内に入り込む |
| **出口手前** | 出口のドア枠、非常口サインの色、フロアマット | 全体の確認を終える前に扉をくぐる |

規律ある立ち回りを維持することで、連続シフトを無事に突破できるようになります。Robloxホラーエンジンのより広範なメカニクスを理解したいプレイヤーは、[Roblox公式プラットフォーム](https://www.roblox.com)のリソースを調べることで、ゲームの物理挙動、ライティングトリガー、サーバー遅延などの理解に役立ちます。

## シフト8の生還と最終ボス戦

シフト8に到達すると、ゲーム性は劇的に変化します。それまでの受動的な観察ループは終了し、強力な呪いの怪異と直接対決するアクティブなサバイバルホラーへと進化します。準備不足のまま挑めば、数秒で命を落とすことになります。

シフト8では、校舎全体が呪いによる完全な封鎖状態に陥ります。廊下が歪み、赤い非常照明が灯り、中央の中庭が決戦の舞台（アリーナ）となります。シフトをクリアするには、ボスの追尾攻撃を回避しながら、周囲に散らばる3つの浄化用封印札を見つけ出さなければなりません。

### ボスのフェーズと攻撃パターン

最終戦は3つのフェーズに分かれており、それぞれ封印札の起動に連動しています。

1. **フェーズ1：シャドウ・プラウラー（影の徘徊者）。** ボスは低い唸り声を上げながら外周の廊下を徘徊します。視界に入ったプレイヤーへの直線突進を仕掛けてくるため、コンクリートの柱を利用して視線を遮りましょう。
2. **フェーズ2：空間跳躍（テレポート）。** 1つ目の封印を起動すると、ボスは短距離を瞬間移動する能力を得ます。地面に渦巻く紫の霧に注意してください。これがボスが出現する前兆となります。
3. **フェーズ3：領域崩壊。** 最終段階では視界が大幅に悪化し、床一面に環境トラップが散乱します。最後の札を中央の祭壇へ運ぶ間、安全地帯の間をダッシュで駆け抜けなければなりません。

| ボスのフェーズ | ボスの能力 | 危険度 | 勝利のための対抗策 |
| :--- | :--- | :--- | :--- |
| **フェーズ 1** | 地上突進、超音波の叫び声 | 中 | 角の柱を利用して射線を切る。 |
| **フェーズ 2** | 短距離ブリンク、幻影の分身 | 高 | 霧の雲を追跡し、足音のない幻影は無視する。 |
| **フェーズ 3** | 呪力の衝撃波、視界/光源奪取 | 極限 | 衝撃波ジャンプ用にスタミナを残し、最後の札を設置する。 |

フェーズ3では冷静さを保つことが重要です。照明が消えたことでパニックに陥り、死亡するプレイヤーが後を絶ちません。自らのルートを信じ、足音に耳を澄まし、儀式を完遂して怨霊を祓いましょう。

## 全エンディングの解放方法

本作には、プレイヤーの戦績、観察の正確さ、シフト8での選択に応じて複数のエンディングが用意されています。すべてのエンディングに到達するには、この**呪術学校の異変 初心者ガイド**で解説したメカニクスの習得が不可欠です。

### 通常生還エンディング（ノーマルエンド）
シフト1から7までを誤答なしでクリアし、シフト8のボスを通常の札配置で撃破することで到達できます。夜明けとともに校舎から脱出し、通常のクリアバッジを獲得できます。

### ループの迷い子エンディング（バッドエンド）
シフト8に到達するまでに異変の判断を3回誤ると、プレイヤーは学校の呪われた領域に飲み込まれます。終わりのない無限回廊に閉じ込められ、ジャンプスケア（恐怖演出）とともに「永遠の呪い」の実績が解除されます。

### 秘密の祓魔師エンディング（トゥルーエンド）
トゥルーエンドを解放するには、シフト4の寮セクターにある隠された「儀式の短剣」を見つける必要があります（コミュニティの検証によると、シフト3で懐中電灯を一度も使わなかった場合のみ、外れかけたロッカーのパネル裏に出現します）。この短剣を持ってシフト8のボス戦に挑むと、怪異を単に祓うだけでなく核を両断することが可能になり、学園崩壊の深層を描く隠された真相が明らかになります。

| エンディング名 | 解放条件 | 必要な異変判定の正確度 | 必要な特殊アイテム |
| :--- | :--- | :--- | :--- |
| **ノーマルエンディング** | シフト1〜8を通常クリア | 100% 正解維持 | なし |
| **バッドエンディング** | 異変報告を3回失敗 | 70% 未満 | なし |
| **祓魔師トゥルーエンディング** | 隠された短剣を使ってボスを撃破 | 100% 正解維持 + 隠し部屋発見 | 儀式の短剣（シフト4） |
| **スピードランナーエンディング** | シフト1〜8を10分未満でクリア | 100% 正解維持かつ高速走破 | なし |

隠しルートに挑戦する前に、この**呪術学校の異変 初心者ガイド**の手順を確認し、正確な前提条件を満たしているか確かめておきましょう。

## よくある質問（FAQ）

### 初心者がゲームオーバーになる最も多い原因は何ですか？
初心者の多くは、視覚的に大きな変化がないことに惑わされ、かすかな音や照明の微細な変化を見落として失敗します。天井を見上げたり、廊下のドアの裏側を確認したりせずに出入口へ突進することが、予期せぬリセットの最大の原因です。

### マルチプレイ時でもこの初心者ガイドの立ち回りは通用しますか？
異変の基本的な出現ポイントは共通ですが、マルチプレイでは正気度の共有や協力観察の要素が加わります。協力プレイモードでは、扉をくぐる前に全員の合意が必要です。チームメイトの1人が誤った扉に入ってしまうと、パーティ全員にペナルティが課されます。

### まったく同じ場所に2回連続で異変が発生することはありますか？
はい、発生します。異変の生成はプロシージャル（ランダム）に行われます。シフト3で逆さまになっていた教室の机が、シフト4では完全に消失しているといったケースもあります。一度通過した部屋だからといって安全だと思い込まないようにしましょう。

### 練習にはどのシフトを周回するのがおすすめですか？
最初の数回は、ソロでシフト1から3をプレイすることをおすすめします。後半の怪異に襲われるプレッシャーがない状態で序盤のシフトを何度も周回することが、標準的な校内の構造を記憶するための最短ルートです。
