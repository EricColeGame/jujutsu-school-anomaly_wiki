## 基本システムの理解：異変の種類と検知方法

呪われた学校での生存は、記憶力、空間把握能力、そして迅速な意思決定にかかっています。本作はクラシックな心理観察ゲームと同様に進行します。プレイヤーは廊下、教室、中庭で構成された所定の周回ルートを巡回し、呪われた異常がないか周囲を慎重に調査します。

異変を発見した場合は、現在の目的に応じて直ちに引き返すか、指定された浄化の結界を発動しなければなりません。廊下に全く異常がない場合は、そのまま前進してシフトカウンターを進めます。判断を誤ると学校の呪いの侵食が進み、死のループロセットへと一歩近づいてしまいます。

コミュニティの報告によると、異変は主に4つの階層に分類されています。

| 異変カテゴリー | 主な兆候 | 脅威度 | 推奨されるプレイヤーのアクション |
| :--- | :--- | :--- | :--- |
| **構造・建築（Architectural）** | ドアの位置ずれ、反転した廊下、階段の消失 | 低 | 直ちに引き返す |
| **視覚・物体（Visual / Object）** | 動く肖像画、増殖した机、血の紋様 | 中 | 基準配置を確認後、引き返す |
| **音響・環境（Audio / Environmental）** | 歪んだ詠唱、逆再生されるチャイム、荒い呼吸音 | 中 | 立ち止まり、音の方向を確認して後退する |
| **実体・出現（Manifestation / Entity）** | 影の呪術師、徘徊するマネキン、浮遊する目玉 | 高 | 目を合わせず、速やかに後退する |

シフト1の間に行われる標準的な部屋のレイアウト把握は極めて重要です。最初のシフトは異変がほとんど発生しない対照環境として機能するため、呪力が校内を歪める前にロッカーの位置、ポスターの内容、窓の反射などを暗記しておくことができます。

## シフト1からシフト8までの攻略チャート

シフトが進むごとに微妙なズレの発生頻度が増加し、点滅する蛍光灯、濃くなる霧、プレイヤーを惑わす幻聴などの環境ハザードが導入されます。

```
[リスポーン / セーフルーム] ──> [メイン廊下] ──> [教室棟] ──> [中庭のアーチ] ──> [決断のゲート]
```

各シフトを進めるには、几帳面なクリアリングが必要です。ドアを勢いよく開けて駆け込むと、正気度（Sanity）ゲージを一瞬で削り取る実体の待ち伏せ異変を誘発することがよくあります。

| シフト段階 | 主な目的 | 異変発生頻度 | 主な危険要因 |
| :--- | :--- | :--- | :--- |
| **シフト1** | 基準レイアウトの暗記 | 極めて低い (0–1) | 油断、ベースラインの見落とし |
| **シフト2** | わずかな物体の変化の特定 | 低 (1–2) | 家具の移動、掲示板の変更 |
| **シフト3** | 音響の確認・監査 | 中 (2–3) | 壁の向こうの囁き声、誤誘導する足音 |
| **シフト4** | 空間の歪みの検知 | 中 (3–4) | 廊下の長さの伸長、非常口標識の消失 |
| **シフト5** | 出現実体の追跡・回避 | 高 (4–5) | 徘徊する霊、教室で揺らめく影 |
| **シフト6** | 呪い浄化の確認 | 高 (5–6) | 汚染された呪符、重力反転した部屋 |
| **シフト7** | 迅速な異変の判別 | 極めて高い (6–7) | 厳しい制限時間、正気度の急低下 |
| **シフト8** | ボス戦前の最終確認 | 極限 (常時) | 現実の崩壊、正常を装う偽の廊下 |

シフト5から7にかけては、構造上のズレとかすかな音響の手がかりが組み合わさった「複合異変（ダブル異変）」が頻繁に報告されています。この**『Jujutsu School Anomaly』エンディング攻略ガイド**では、曖昧で判断に迷うシフトはすべて「異変あり」として扱うことを推奨します。迷った際に引き返すことで発生するタイムロスはごく僅かですが、アクティブな異変を通り抜けようとすると即座に不可避のゲームオーバーを引き起こす可能性があるためです。

## 全エンディングの解放方法

本作には、観察の正確さ、呪符の収集状況、そして最終決戦での立ち回りに応じて複数のマルチエンディングが用意されています。ランを開始する前に、本**『Jujutsu School Anomaly』エンディング攻略ガイド**のこのセクションを参照して目指すルートを決めておきましょう。

| エンディング名 | 分類 | 主な達成条件 | 結末の概要 |
| :--- | :--- | :--- | :--- |
| **呪いに呑まれし者（Consumed by the Curse）** | バッドエンド | 異変チェックに3回失敗、または正気度が0になる | 無限に続く廊下のループに永遠に閉じ込められる |
| **臆病者の逃走（The Coward's Departure）** | ノーマル/中立エンド | シフト4の途中で非常口から脱出する | 生還は果たすが、学校は呪われたまま残る |
| **浄化の夜明け（Purified Dawn）** | グッドエンド | ミスなしでシフト8をクリアし、呪遺物を拾わない | 結界がリセットされ、プレイヤーは無事に脱出する |
| **厄災の器（Vessel of Calamity）** | シークレットエンド | 宿儺を彷彿とさせる4つの呪いの遺物をすべて収集する | 古の呪術に肉体を乗っ取られ、器と化す |
| **特級祓魔（Special Grade Exorcism）** | トゥルーエンド | シフト8をクリア後、最終ボスを召喚して撃破する | 呪いの完全消滅。特別なクリアバッジを獲得 |

### トゥルーエンドへのステップ・バイ・ステップ手順：
1. 誤判定を1回以下に抑えながらシフト1から7までをクリアする。
2. シフト3およびシフト6にて、解錠された化学実験室と資料室に入り、「浄化の護符」の破片（2枚）を回収する。
3. シフト8を進行し、非常ゲートには向かわず「儀式の中庭」へと進む。
4. 中央の祭壇を調べて結界を解除し、クライマックスバトルを開始する。

## 最終ボス戦：特級異変の攻略戦略

観察シフトを生き延びると、[Roblox platform](https://www.roblox.com)上で待ち受ける真のボス戦へと直結します。それまでのステルスやパズル主体の観察ループとは異なり、最終決戦では戦闘反射神経、スタミナ管理、そして的確な回避能力が試されます。

特級異変（Special Grade Anomaly）は、3つの明確なフェーズにわたって姿を変えます。完全なる祓魔を成し遂げるには、敵の攻撃予兆（予備動作）を理解することが不可欠です。

| ボスフェーズ | 主な攻撃パターン | 危険度 | 推奨される対策 |
| :--- | :--- | :--- | :--- |
| **フェーズ1：影の弾幕** | 射出される黒い触手、地面からのトゲ | 中 | 横方向にダッシュし、床の攻撃マーカーをジャンプで避ける |
| **フェーズ2：領域の歪み** | 画面操作の反転、赤色エネルギービーム | 高 | 移動キーの入力を反転させる。石柱の背後に隠れる |
| **フェーズ3：呪厄の天災** | フィールド全体へのAoE衝撃波、影の分身 | 極限 | 発光するコアに火力を集中。浄化の護符を使用する |

### 実戦タクティクス解説

フェーズ1では、中距離を維持してください。近づきすぎると、ボスのガード不能な薙ぎ払い攻撃によって体力の3分の2を一気に削られます。床に赤い攻撃予兆が出現した際にすぐダッシュで離脱できるよう、スタミナゲージは常に40%以上をキープしておきましょう。

フェーズ2が始まるとフィールドが視覚的に反転し、カメラアングルが激しく歪みます。コミュニティの上級プレイヤーは、領域展開が発動した瞬間に半秒ほど動きを止め、照準を画面中央に再調整することを推奨しています。操作が重く感じられてもパニックにならず、中庭の外周に点在する石灯籠の後ろに身を隠すことを優先してください。

フェーズ3は純粋なDPS（与ダメージ）レースとなります。ボスはフィールド全体に幻影の分身を召喚します。外周の幻影は無視し、紫色の呪力の火花を放っている中央の本体だけを狙ってください。完成させた「浄化の護符」を発動するとボスを5秒間完全にスタンさせることができ、露出したコアを攻撃してトゥルーエンドのムービーを発生させることが可能になります。

## 必須装備、アイテム、および正気度（Sanity）管理

ラン全体を通して、ユーティリティアイテムを適切に管理することで、些細な感覚の罠に引っかかるのを防ぐことができます。所持するすべてのアイテムは移動速度や知覚に影響を与えるため、リソースのバランス調整はこの**『Jujutsu School Anomaly』エンディング攻略ガイド**において極めて重要な要素です。

| アイテム名 | 入手場所 | 効果時間 / 使用回数 | 戦略的用途 |
| :--- | :--- | :--- | :--- |
| **標準懐中電灯** | セーフルームの机 | バッテリー無限 | 隠された印を照らし出す。ただし徘徊する敵を引き寄せる |
| **呪いの蝋燭** | 職員室（シフト2以降） | 90秒間燃焼 | 青い炎の反応によって異変の存在を知らせる |
| **清めの塩** | カフェテリアの倉庫 | 3回使用可能 | 廊下の好戦的な実体を一時的に退散・足止めする |
| **精神安定剤** | 保健室の薬品棚 | 2回使用可能 | 正気度を50%回復し、偽の幻聴をかき消す |
| **封印の護符の破片** | 隠し教室 | パッシブ用クエストアイテム | トゥルーボスのエリアゲートを解錠するために必要 |

### 実践的な正気度維持のヒント
* **ライトのこまめなオン・オフ：** シフト5以降では、懐中電灯を常時点灯させていると徘徊する悪霊を引き寄せてしまいます。部屋の角を素早く確認する時だけ点灯し、メインの廊下を移動する際は消灯しておきましょう。
* **オーディオ設定の最適化：** 異変の60%以上は、遠くの時計が逆回転する音や背後の微かな足音など、繊細な音響キューを伴います。3D空間オーディオを有効にしたヘッドフォンを着用することで、生存率は大幅に向上します。
* **画面端のビネット（暗がり）に注意：** 画面の縁が暗くなり、影が内側に迫ってきたら、キャラクターの正気度が危険水準に達している合図です。この状態になると「偽の異変（幻覚）」が発生し始め、致命的な判断ミスを引き起こします。

## シフト生存チェックリストと周回ルート最適化

最高ランクを獲得し、ミスなくスムーズに攻略するために、新しいシフトの廊下に足を踏み入れるたびに以下の標準化された部屋確認手順を実行してください。

* **チェック1（進入ゲート）：** 頭上の非常口サインと蛍光灯の色を確認する。
* **チェック2（ロッカー通路）：** ロッカーの扉がすべて閉まっているか、窓ガラスに手形がついていないかを確認する。
* **チェック3（教室の窓）：** 窓の格子越しに中を覗き、机が綺麗に整列しているか確認する。
* **チェック4（天井と床）：** 重力が反転したようなシミや、天井から滴る黒い水がないか確認する。
* **チェック5（中庭の門）：** 門に掲示されている横断幕の文字が正しく書かれており、左右反転していないか確認する。

この体系化されたルートを厳守することで、異変の発見が無意識の習慣となり、序盤のシフトを難なく突破して、最終決戦のために貴重なリソースを温存できるようになります。

## よくある質問（FAQ）

### 廊下で異変や実体に追われた場合はどうすればいいですか？
敵をすり抜けて前方にダッシュしようとしてはいけません。即座に180度反転し、入ってきたセーフゾーンの扉に向かって全力で走ってください。スタミナが切れそうな場合は、背後の床に「清めの塩」を使うことで実体を一時的に足止めできます。

### 初回プレイでトゥルーエンドを解放することはできますか？
はい、可能です。シフト3と6で「浄化の護符」の破片を両方見つけ、すべての異変を正確に判別し、シフト4の非常口（臆病者の逃走エンド）を使わずにクリアすれば、1周目でも達成できます。

### 引き返したのにシフトカウンターが進まない（認識されない）のはなぜですか？
引き返した後にシフトが進まない場合、通常の環境オブジェクトを異変と誤認した（偽陽性）か、廊下の判定トリガーラインを越える前に引き返してしまったかのいずれかです。最終判断を下す前に、必ず廊下の少なくとも半分までは進むようにしてください。

### シフト7で正気度の減少が早すぎるのを防ぐにはどうすればいいですか？
正気度は、発生している異変の近くに留まり続けたり、実体を直視したりすることで急速に減少します。正気度を保つためには手早く部屋を確認し、画面の縁が暗くなったら保健室の精神安定剤を使用し、影の人物にライトを当て続けないようにしてください。本**『Jujutsu School Anomaly』エンディング攻略ガイド**のルート手順に従うことで、正気度が尽きる前に素早くクリアすることができます。
