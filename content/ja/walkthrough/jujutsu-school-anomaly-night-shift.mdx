## 異変の種類一覧と徹底解説

何が「異常」であるかを見抜く力こそ、本作で生き残るための根幹スキルです。本作の異変は、必ずしも大きな音を立てて襲ってくるものばかりではありません。むしろ、最も静かな異変こそが、熟練プレイヤーをも陥れる罠となります。

異変は大きく分けて「構造・環境」「音響・雰囲気」「ドッペルゲンガー」「徘徊する呪霊」の4カテゴリーに分類されます。それぞれの危険度を把握しておくことで、**呪術学校アノマリー夜勤**の明滅する蛍光灯の下でも瞬時に正しい決断を下せるようになります。

### 1. 構造・環境の異変
学園内の配置が静かに改変される異変です。突然板打ちされて塞がれた教室のドア、視線がプレイヤーを追尾してくる呪術師の肖像画、5台並んでいたロッカーに突如6台目が追加されているといったケースがあります。直接追いかけてくることはありませんが、正常と誤認して通り過ぎるとシフトがリセットされます。

### 2. 音響・雰囲気の異変
音の合図は極めて重要です。頭上から聞こえる濡れた足音、遠くからの詠唱、逆再生される校内チャイムなどが該当します。また、急激な気温低下、蛍光灯の不規則な明滅、天井の換気口から垂れ落ちる血などの環境変化もこのカテゴリーに含まれます。

### 3. ドッペルゲンガーと歪んだNPC
見覚えのある生徒や教職員の姿をした人影が、廊下に直立不動で立っていることがあります。姿勢が不自然にねじれていたり、顔が黒く塗りつぶされていたり、意味不明な言葉を呟いている場合は絶対に近づいてはいけません。即座に引き返してください。

### 4. 徘徊する呪霊（アクティブエンティティ）
廊下を実際に徘徊する敵対的な怨霊です。静的な環境異変とは異なり、視界に入ったまま立ち止まっていると追跡してきます。即座に視線を逸らして退却するリアクション速度が生死を分けます。

| 異変の名称 | カテゴリー | 視覚・聴覚的特徴 | 危険度 | 正しい対処法 |
| :--- | :--- | :--- | :--- | :--- |
| **啜り泣く肖像画** | 構造 | 歴代教官の肖像画から絵の具（血）が滴り落ちる | 低 | 直前の通路へ引き返す |
| **反転した教室** | 環境 | 机と椅子が天井に逆さまに張り付いている | 中 | 教室に入らず、即座にUターンする |
| **亡霊の足音** | 音響 | 立ち止まると止まる重い足音が聞こえる | 低 | 立ち止まって方角を確認後、道を逆戻りする |
| **歪んだ呪術師** | ドッペルゲンガー | 生徒モデルが首を異常な角度に折って硬直している | 高 | 目を合わせず、進入したドアから即座に逃げる |
| **床の顎（フロアマウ）** | 呪霊 | 廊下の床に黒い呪詛が広がり牙を形成している | 高 | 前進せず、直ちにUターンする |
| **影の潜伏者** | 呪霊 | 中庭の奥からこちらを見つめる巨大な黒い影 | 即死級 | 懐中電灯を消し、ゆっくり後退してドアを出る |

## シフト別攻略ガイド：シフト1からシフト8までの生還手順

ゲームをクリアするには、コミュニティで「シフト1〜8」と呼ばれる全8回の巡回サイクルを突破する必要があります。シフトが進むにつれて異変の発生頻度が上がり、内容はより見分けにくくなり、攻撃的な怨霊の出現が重なるようになります。

**呪術学校アノマリー夜勤**を制覇するには、段階的なフェーズ管理が欠かせません。以下にシフト別の攻略手順をまとめました。

```
[シフト1 - 2: 基礎確認] ➔ [シフト3 - 5: 異変激化] ➔ [シフト6 - 7: 高緊張フェーズ] ➔ [シフト8: 最終ボス戦]
```

### シフト1〜2：基本レイアウト把握フェーズ
序盤のシフトは、通常状態の基準（ベースライン）を頭に叩き込む時間です。シフト1では以下の項目を記憶しましょう：
* メイン廊下の壁にあるポスターの枚数（標準は4枚）。
* 非常口誘導灯の色（標準は鈍い緑色）。
* 主通路にある自動販売機の正確な配置場所。

シフト1とシフト2で出現する異変は、ドアが丸ごと消失していたり大量の血痕が広がっていたりと、大がかりで分かりやすいものばかりです。焦らずメンタルマップを構築し、各部屋を確認してから進みましょう。

### シフト3〜5：難化とドッペルゲンガーの出現
シフト3以降、学園はプレイヤーを本格的に欺き始めます。修練場ゲートや食堂の入り口付近にドッペルゲンガーが出現し始めます。安全なNPCの姿を模倣することが多いですが、セリフのフォントが崩れていたり、句読点がおかしな位置にあったりします。

シフト4および5では、音響系の異変が急増します。必ずステレオヘッドホンを装着してプレイしてください。前の周回にはなかったかすかな心音や機械のノイズが聞こえたら、異変と判断してすぐに引き返しましょう。

### シフト6〜7：高難度シークエンス
シフト6に到達すると、複数の微細な異変が同時に発生することがあります。例えば、時計の針が逆回転しているのと同時に、ポスターのテクスチャがわずかに変化しているケースです。1つでも異変を見つけたら、それが引き返す十分な証拠になります。異変を特定できたなら、他の場所を隅々まで確認して時間を浪費してはいけません。

シフト7には厳しい制限時間が存在します。1つの廊下区画に45秒以上とどまると、天井から闇が侵食し始め、強制的に即死トラップが発動します。

| シフト帯 | 平均異変数 | 主な危険要素 | 推奨移動速度 | 重要チェックポイント |
| :--- | :--- | :--- | :--- | :--- |
| **シフト 1 – 2** | 1巡につき1件（明瞭） | 明らかな壁の裂け目、浮遊する備品 | 慎重／通常歩行 | 中央廊下、掲示板 |
| **シフト 3 – 4** | 1巡につき1〜2件（中程度） | ドッペルゲンガー、歪んだ音声 | 一定のペースを維持 | 食堂の扉、中庭の祠 |
| **シフト 5 – 6** | 1巡につき2件以上（微細） | 照明の変化、小物の消失 | 中速／ダッシュ禁止 | 道場の武器棚、階段の影 |
| **シフト 7** | 1巡につき2〜3件（動的） | 移動する怨霊、時間制限の影 | 迅速／迷わず判断 | 西棟、ロッカーエリア |
| **シフト 8** | スクリプト進行 | 最終ボス遭遇戦／脱出フェーズ | ダッシュ／回避機動 | 儀式の広間、正門 |

## 上級者向け生存戦略とよくあるミス

多くのプレイヤーが些細なミスの積み重ねにより、シフト5〜7の間で足止めを食らいます。**呪術学校アノマリー夜勤**の極限状態を乗り切るには、洗練された観察習慣と規律が必要です。

### 「3点スキャン」をマスターする
新しい廊下区画に入った際、中央を漫然と走ってはいけません。以下の「3点スキャン」を徹底してください：
1. **目線の高さ（水平）：** 絵画、ドアノブ、窓に映るシルエットを確認。
2. **足元（下方向）：** 呪われた血だまり、不揃いな靴、物体から切り離された影を確認。
3. **天井（上方向）：** 照明器具の配列、天井タイルの浮き、這い寄る触手を確認。

慣れればこのスキャンは4秒以内に完了し、見落としがちな構造的異変の約80%を防止できます。

### 生死を分ける音の聞き分け
**呪術学校アノマリー夜勤**をプレイする際、ゲーム音をミュートにしたり、大音量のBGMを流しながらプレイするのは厳禁です。「影の潜伏者」などの危険な怨霊は、姿を現す約2秒前にかすかな高周波の耳鳴り音を発します。その音こそが、ライトを消して後退するための唯一の猶予です。

| よくあるミス | 全滅につながる理由 | プロのアドバイス |
| :--- | :--- | :--- |
| **無謀なダッシュ** | 異変を認識する前に境界線を越えてしまい即死する | 観察中は歩き、敵から逃げるときのみダッシュを使う |
| **細かなテクスチャ変化の無視** | ポスターの文字や肖像の小さなズレも完全な異変と判定される | ほんの少しでも違和感を覚えたら、直感を信じて引き返す |
| **徘徊する霊の直視** | 長時間視線を合わせると追跡モードがトリガーされる | 周辺視野で捉えたら視線を落とし、素早く後退する |
| **初期配置の失念** | もともと配置されていた不気味な小物を動的異変と誤認する | 異変のないシフト1で本来の備品配置を完璧に覚える |
| **懐中電灯の常時点灯** | 光を嫌う一部の怨霊はライトの光束に直接引き寄せられる | 暗い部屋に入る際のみ、小刻みにオン・オフを切り替える |

## ラスボス戦攻略：シフト8のクライマックスと全エンディング条件

シフト8に到達すると、ゲーム性は静かな観察シミュレーターから、息もつかせぬサバイバルボス戦へと激変します。シフト7の境界を越えると、見慣れた学園の廊下は断片化した儀式空間へと歪み、異変そのものが攻撃的な実体となって襲いかかってきます。

**呪術学校アノマリー夜勤**のクライマックスでは、学園の「呪いの核（Cursed Core）」との直接対決が待ち受けています。異変の報告ではなく、環境ギミック、音響パズル、ダッシュフェーズを駆使したアリーナスタイルの試練を突破しなければなりません。

```
シフト8の進行フロー：
[廊下の崩壊] ➔ [呪符の浄化パズル] ➔ [ボスアリーナの回避] ➔ [正門への最終脱出]
```

### フェーズ1：崩壊する廊下
背後の廊下が虚無へと崩れ落ちていきます。前方にダッシュしますが、床の顎や歪んだ鏡のフレームを踏まないよう注意してください。頭上のアーチを注視し、紫色の呪力で発光しているアーチがあれば、スライディングや左右へのステップで反対側に回避します。

### フェーズ2：学園の結界呪符の浄化
中央の中庭アリーナで、ボスは3つの汚染された結界呪符を召喚します。ボスの広範囲薙ぎ払い攻撃を回避しながら、各呪符をインタラクトして浄化します：
* **赤の呪符：** インタラクトボタンを3秒間長押し。落下してくる瓦礫に注意。
* **青の呪符：** 浄化中、一時的に移動操作が反転（インバート）する。
* **金の呪符：** ドッペルゲンガーの幻影を召喚。懐中電灯の光を素早く当てて消滅させる。

### フェーズ3：正門への最終脱出
すべての結界呪符を浄化すると、学園正面の結界が霧散します。ボスが「領域展開」を放つ前に、鳥居の出口に向かってラストスパートをかけます。ボスの放つ最終衝撃波をジャンプで飛び越えられるよう、スタミナゲージは常に20%以上を維持してください。

| エンディング名 | 到達条件 | ボス撃破 | ストーリーの結末 |
| :--- | :--- | :--- | :--- |
| **真の呪術師エンド（True Sorcerer）** | シフト8でノーダメージかつ3つの呪符をすべて浄化して脱出 | 達成 | 学園の呪いを完全に解呪し、「1級査察員」のバッジを獲得 |
| **通常脱出エンド（Standard Escape）** | 呪符をすべて浄化せず、結界門を強行突破してシフト8をクリア | 一部 | 生きて夜を越えるが、学園は依然として闇に隔離されたままとなる |
| **ループの囚われ人エンド（Trapped in the Loop）** | シフト7または8で3回連続で異変の判別ミスを犯す | 失敗 | 自らが異変と化し、次の警備員を待つ存在として廊下を彷徨う |
| **領域呑縛エンド（Domain Consumption）** | 最終ボスのダッシュフェーズでスタミナ切れになり捕まる | 失敗 | ボスの領域に呑み込まれ、バッドエンド専用ジャンプスケアが発生 |

コミュニティの情報によると、「真の呪術師エンド」を解除すると限定の装飾称号と特殊なランタンスキンが入手でき、2周目以降の暗所における異変判別が格段に有利になります。

## よくある質問（FAQ）

### 呪術学校アノマリー夜勤のプレイ中、怨霊に見つかったらどうすればいいですか？
**呪術学校アノマリー夜勤**で敵対的な怨霊に見つかった場合、直視し続けたり前方へ強行突破しようとしては危険です。即座に反転して視線を切り、懐中電灯をオフにして前の部屋のドアへと退却してください。大半の徘徊呪霊は、直前の安全な廊下へと戻ることでデスポーン（消滅）します。

### ゲーム内のシフトは全部でいくつありますか？
標準的な攻略ルートでは「シフト1からシフト8」までの全8ステージが存在します。シフト1から7は、環境・音響・実体の異変を特定してカウンターを進める構成です。シフト8はクライマックスとなるボス戦と脱出シークエンスであり、行動によって最終エンディングが分岐します。

### 異変の出現パターンは周回ごとに完全ランダムですか？
はい。固定された構造的アンカー（基本レイアウト）は共通ですが、各シフトで発生する具体的な異変は膨大なイベントプールからランダムに抽選されます。ある周回のシフト3で音響異変に遭遇しても、次のプレイではドッペルゲンガーや反転教室が出現することがあります。

### 夜勤はマルチプレイ（CO-OP協力プレイ）で遊べますか？
アクティブなロビーの設定に応じて、ソロまたは少人数スクワッドでの進入が可能です。協力プレイではコミュニケーションが命となります。1人のプレイヤーが間違った判断をして出口を進むとチーム全員の進行がリセットされるため、異変があるかどうかは必ず全員で確認・合意してから進む必要があります。
